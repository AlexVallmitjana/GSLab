User Manual

GSLab uses two windows: the main GSLab window and the Image window. The GSLab window has a top panel that displays the phasor plot and a bottom panel organized into seven tabs, each providing access to a specific set of functions. The Image window displays all images loaded into the software.

Phasor Plot panel

GSLab window and Image window.

This panel displays the phasor plot. Hovering over the phasor plot displays a circular cursor; use the mouse scroll wheel to change its size. The cursor's center coordinates appear in the upper-left corner. When files are loaded, pixels whose phasor coordinates fall within the cursor are displayed in the cursor's color. Click the phasor plot to fix the cursor in place; a new cursor, with a different color, then follows the mouse pointer. When at least one cursor is present, a red X button appears in the upper-right corner. Click it to clear all cursors from the plot.

File tab

Loaded files appear in the main panel. Use the checkbox beside each filename to include or exclude that file from display and analysis.

+ Quick load button: prompts the user to select one or more files to load.

Context menu options (right-click):

Calibration File: Sets the selected file as a calibration file. GSLab calculates the photon-weighted average phasor coordinates of the file's phasor distribution and assigns the lifetime specified in the Calibration Lifetime box in the Calibration Panel.

Load menu: an alternative to the + button when you need to specify the file format. GSLab remembers the last-used folder separately for each menu item.

Tif Sequence: prompts the user to select one or more TIFF files.

FLAME raw: prompts the user to select a folder containing raw FLAME images.

Leica FALCON SnG: prompts the user to select a folder containing groups of three or four TIFF files exported from the Leica FALCON as S and G coordinates using Save phasor GS - Fixed Range in LASX. These files contain precomputed phasor coordinates for the first harmonic only. To export them:

1. In the LAS X FLIM/FCS window, select the Intensity tab above the images.

2. In the FLIM tab of the left-hand menu, locate the Save Image button at the bottom.

3. Click Save Image to open the Save Image window:

4. Select Tiff tab.

5. Select the Save Phasor GS checkbox.

6. Select the Fixed Range radio button.

7. Set Factor or Range to Per Grey Level, then enter 1 in the edit box.

Zeiss lsm: prompts the user to select one or more Zeiss LSM files.

FLIM LABS json: prompts the user to select one or more FLIM LABS JSON files.

JenLab ptu: prompts the user to select one or more JenLab PTU files (courtesy of Martin Skorsetz).

PicoQuant ptu: prompts the user to select one or more PTU files. GSLab comes with an experimental native ptu reader. For full ptu versatility, Python installation and C.Gohlke's ptufile library [GitHub] is recommended.

Becker & Hickl sdt: prompts the user to select one or more SDT files. This option requires Python and C.Gohlke's sdtfile library [GitHub]. Recommended version Python3.11.

SimFCS ref: prompts user to select ref or r64 file(s).

Trace txt/csv: prompts user to select txt or csv files with single traces.

Saved Session: loads a previously saved session including files and settings

Save menu:

SimFCS ref: generates a phasor-coordinate file containing the first two harmonics.

Current session: prompts the user to choose a save location and filename for the current settings and the paths to all loaded files.

Move:

Top/up/down/bot: Moves the selected file to the specified position in the list, changing the order in which files appear in the Image window and in exported images.

Odd/even: Reorders the files by alternating items between two groups, effectively splitting the current list into two halves.

Check All/None/Invert/Alternate: Checks all files, unchecks all files, inverts the current selection, or checks alternating files. These settings determine which files are displayed and analyzed.

Emphasis:

Selected: Opens the color picker to choose the color used to display phasor data from the selected file.

Checked: Opens the color picker to choose the color used to display phasor data from all checked files.

None: Removes file-specific emphasis and displays all phasor data together using a single density colormap.

Clear All/Unchecked: Removes either all files or only unchecked files from memory.

▴ Calibration Panel button: expands or collapses the calibration panel.

Apply checkbox: enables or disables application of the current calibration to loaded files.

File/Manual radio button: allows you to choose between file-based calibration and manually entered calibration values.

File mode: The calibration panel displays a table with three columns:

The first column contains a text tag used to match files to a calibration. The default value is All, which applies the calibration to every file. If you enter a specific text string, only files whose names contain that string will use the selected calibration file.

The second column contains the lifetime associated with the calibration file. You can edit this value.

The third column displays the filename used for calibration.

Manual mode: Two input boxes are displayed:

Phase shift: applies the specified phase shift to the data, in radians.

Modulation factor: applies the specified modulation factor to the data. The factor is normalized to unity.

Calibration Lifetime box: Enter the lifetime to assign to the next file selected as a calibration file.

Clear button: clears all calibration files from the calibration panel.

Image tab

Controls image processing and the display of intensity images before the phasor transform is computed.

Image tab.

Intensity threshold input boxes: sets the lower and upper intensity limits used when rendering images.

Slide bar also sets the lower and upper intensity limits used when rendering images.

Relative checkbox: determines whether intensity limits are relative to each file's dynamic range or are specified in absolute intensity units.

Auto button: automatically sets the intensity range using a data percentile specified in Preferences.

Intensity histogram panel displays the intensity histogram for each loaded file.

Log plot checkbox: displays the intensity histogram on a logarithmic scale. This is useful when pixel counts span a wide range.

Log intensity checkbox: displays images using logarithmic intensity scaling to accommodate a high dynamic range.

HDR intensity checkbox: displays images using a pixel-wise local dynamic range to accommodate high-dynamic-range data.

Excess to zero checkbox: excludes pixels whose intensity reaches or exceeds the upper intensity threshold.

Gaussian filter text box: applies a Gaussian filter to images. Enter the filter size in pixels.

Threshold/cursors dropdown:

Threshold: creates masks based on the intensity thresholds.

Cursors: creates masks based on the cursors placed on the phasor plot.

To mask: creates a mask using the method selected in the dropdown menu.

Apply mask checkbox: enables or disables application of the current mask to the loaded data.

Invert checkbox: inverts the current mask.

Label checkbox: converts a binary mask into a connected-component label matrix, assigning a different label to each disconnected object.

Integrate checkbox: integrates the pixels within the mask for phasor plotting and decay analysis. If the mask is an indexed image (for example, one created using the Label checkbox or loaded from a cell-segmentation file), each labeled object is treated as a separate entity.

Clear: deletes the current mask.

Save mask button: saves the current masks to a file: PNG for a single mask or a stacked TIFF for multiple masks.

Load mask button: loads images to use as masks. A single loaded mask is applied to every loaded file. If multiple masks are loaded, they are applied sequentially to the loaded files. For a multi-slice TIFF, each slice is applied to the corresponding loaded file. You can also load images containing integer labels; these are treated as region labels and can be used to integrate the phasor coordinates of each region (Image tab, Integrate checkbox) or export average phasor data for each region (Export tab, Masked obj data checkbox).

Overwrite checkbox: determines whether a newly loaded mask replaces the current mask or is combined with it.

Phasor tab

Controls the phasor transform computation and the associated measurements.

Phasor tab.

Phasor filter dropdown: selects the filter type: median, Gaussian, or wavelet. The wavelet option requires the Wavelet Toolbox.

Filtering size box: sets the median-filter kernel size, the Gaussian-filter standard deviation, or the wavelet support for Daubechies and Symlet wavelets.

Wavelet support dropdown: sets the support of the selected wavelet family. This option requires the Wavelet Toolbox.

Times box: sets the number of times the filter is applied.

Level box: sets the wavelet denoising level. This option requires the Wavelet Toolbox.

S range boxes: sets the lower and upper limits of the S axis in the phasor plot.

Auto button: automatically sets the S-axis limits using a data percentile specified in Preferences.

G range boxes: sets the lower and upper limits of the G axis in the phasor plot.

Auto button: automatically sets the G-axis limits using a data percentile specified in Preferences.

Both button: automatically sets both the G- and S-axis limits using data percentiles specified in Preferences.

Color range boxes: sets the lower and upper limits of the color range. Angular quantities use turns as their units; radial quantities use phasor units.

Norm color units: switches between specifying the color range in units of the unit circle and specifying it in the selected physical units.

Auto button: automatically sets the color range using a data percentile specified in Preferences.

Centering boxes: sets the G and S coordinates of the center used for a custom measured quantity.

Phasor resolution box: sets the number of bins used to compute the phasor plot.

Plot HR button: computes the phasor plot using the high-resolution images.

Save Cursors button: saves the current cursor positions, dimensions, and colors to a file.

Load Cursors button: loads cursor positions, dimensions, and colors from a file.

Measured Quantity radio buttons:

S: generates a color gradient based on the S coordinate.

G: generates a color gradient based on the G coordinate.

Phase: generates a color gradient based on polar phase.

TauPhase: generates a color gradient based on polar phase and calculates the corresponding lifetime.

Mod: generates a color gradient based on polar modulation.

TauMod: generates a color gradient based on polar modulation and calculates the corresponding lifetime.

NormPhase: generates a color gradient based on pseudo-phase.

TauNorm: generates a color gradient based on pseudo-phase and calculates the corresponding lifetime.

CustomRadial: generates a custom radial color gradient. You must specify the center coordinates.

CustomAngular: generates a custom angular color gradient. You must specify the center coordinates.

Display tab

Controls the appearance and formatting of the phasor plot.

Display tab.

Harmonic # numeric box: displays the phasor plot for the selected harmonic. Values greater than 1 are shown in red as a warning.

Phasor style radio button:

Lifetime: sets the S and G axis ranges for lifetime phasors and displays the universal semicircle.

Spectral: sets the S and G axis ranges for spectral phasors and removes the universal semicircle.

Int vs Mag: replaces the phasor plot with a histogram of pixel intensity versus the measured phasor quantity selected in the Phasor tab.

Plot embellishment:

Lines checkbox: draws the universal semicircle in lifetime mode or the unit circle in spectral mode.

Axes checkbox: displays the G and S axes.

Axes font size box: sets the font size of the S and G axis labels.

Ticks checkbox: adds tick marks for selected lifetimes or wavelengths, depending on the excitation frequency or spectral band.

Tick font size box: sets the font size of the tick labels.

Grid checkbox: displays a grid appropriate to the selected phasor representation.

Tick count box: sets the number of ticks to display.

Density representation:

Log density checkbox: displays phasor density on a logarithmic scale, making low-count bins more visible.

Normalize by file checkbox: normalizes the phasor-density range independently for each loaded file, so files are displayed using comparable color ranges regardless of their data distributions.

Contours checkbox: adds contour lines to represent lower-density regions in the phasor plot.

Only checkbox: hides the heatmap, leaving only the contour lines.

Other display options:

Quantity background color checkbox: displays the color gradient associated with the measured quantity selected in the Phasor tab.

Soft masks checkbox: overlays cursor or measured-quantity colors on the intensity images. In soft-mask mode, the colors are modulated by image intensity; in hard-mask mode, the colors are displayed independently of intensity.

Image window tiling checkbox: forces images in the Image window to use a tiled layout.

Image window tiling numeric boxes: sets the number of rows and columns used to arrange the loaded files.

Margins checkbox: adds or removes margins between images in the Image window.

Flip even rows checkbox: arranges image tiles in a zigzag pattern to accommodate certain mosaic-stage scan paths.

Phasor dimension plot:

Plot Decay button: plots the temporal or spectral curve for each file.

Norm checkbox: normalizes each plot to its maximum value.

Log checkbox: uses a logarithmic scale for the intensity axis in decay plots.

Bars/Lines radiobutton: selects the display style for decay plots.

Phasor integral boundary:

Spectral band numeric boxes: sets the wavelength limits, in nanometers, for the spectral phasor transform. This option is available only in spectral display mode.

Bin correction checkbox: adjusts the tick limits to account for bin width. Check this option if the spectral limits refer to the centers of the first and last bins. Leave it unchecked if they refer to the beginning of the first bin and the end of the last bin.

Source frequency numeric box: sets the lifetime excitation laser frequency used to define the trigonometric period of the phasor transform. This option is available only in lifetime display mode.

Cluster tab

Performs automated clustering of phasor distributions in phasor space.

Cluster tab.

Model dropdown: selects the clustering model (GMM is recommended). Depending on the model, you must place cursors to specify the initial cluster locations or the number of clusters, K.

GMM: Gaussian mixture model. Uses the expectation-maximization algorithm to estimate a mixture of K Gaussian components.

K-means: K-means clustering. Groups data by minimizing within-cluster distances; this is equivalent to seeking compact, well-separated clusters.

Cursors: uses the placed cursors as seeds and expands their regions according to a Voronoi partition.

Train model: trains the selected model using the data currently displayed in the phasor plot.

Clear model: clears the trained model.

Apply model: applies the trained model again to the currently displayed data.

Phasor display style:

Contour of model: displays the sum of the Gaussian components as a single contour plot.

Contour separate clusters: displays each cluster's Gaussian component as a separate contour plot.

Ellipse with percentage of data: displays a contour for each Gaussian component that encloses the percentage of data specified in the text box.

Scatter plot: overlays the data points on the phasor plot.

Voronoi cells: draws the Voronoi cells.

Image display style:

Hard assign: assigns each pixel the color of the Gaussian component with the highest posterior probability.

Probability assign: colors each pixel using a mixture of the component colors, weighted by the posterior probabilities of the Gaussian components for that pixel.

Blending percentage: smooths the color-mask image to blend neighboring regions.

Override measured quantity for export: when checked, replaces the measured-quantity image options in the Export tab with GMM-colored image options, allowing you to export the clustering results.

Unmix tab

Defines pure components for multi-harmonic, multi-component phasor unmixing.

Unmix tab.

Compute LR button: performs unmixing and generates the selected exports using the low-resolution versions of the loaded images.

Compute HR button: performs unmixing and generates the selected exports using the high-resolution versions of the loaded images.

Source radio buttons:

Manual: use the Components panel to enter the lifetimes of pure single-exponential components manually.

File: select loaded files to use as empirical components for unmixing.

Cursors: use point-and-click cursors to define components. A maximum of three components is supported because of the harmonic limitation.

Components panel: (Manual mode).

(+/-) buttons: adds or removes an unmixing component.

Colored circle button: opens the color palette to choose the color assigned to the component.

Lifetime numeric box: sets the lifetime of the component.

Components panel (File mode): displays the list of loaded files. Check individual files to use them as empirical components. For each checked file, GSLab calculates the photon-weighted average phasor coordinates and assigns the color selected in the manual Components panel.

Draw components checkbox: displays the positions of the unmixing components on the phasor plot.

Add lines checkbox: draws lines between consecutive components on the phasor plot.

Export fraction images checkbox: when enabled, exports each component as an image and exports the associated raw data in the selected formats:

Color components checkbox: exports fractional-intensity images using the component colors selected in the Components panel.

Single Image checkbox: combines the unmixing results into a single image instead of exporting separate images for each file and component. The layout uses the row and column settings in the Display tab.

Group by file checkbox: determines how results are grouped: either one image containing all components for each file, or one image containing all files for each component. The layout uses the row and column settings in the Display tab.

Add margins checkbox: adds or removes margins between tiles in the combined images.

Merge components checkbox: creates a merged image using the component colors selected in the Components panel. This option is available when Group by file is unchecked).

Export fractions × intensity: determines whether photon-fraction images represent the absolute number of photons assigned to each component or the relative fraction assigned to each component (fractions summing to one). In either case, the output is normalized to the dynamic range of an 8-bit image.

Export fraction CSV checkbox: exports the calculated fractional-intensity values for all pixels that pass the thresholds to a spreadsheet, with one column per component.

Include intensity checkbox: adds each pixel's intensity value as the first column of the exported CSV file. This option is available only when Export fraction csv is checked).

Export ratiometric checkbox: computes a ratiometric image using two components, according to X/(X+Y).

Component numeric boxes: selects the X and Y components used for ratiometric imaging.

Export ratio CSV checkbox: exports a spreadsheet containing the calculated ratiometric value for each pixel.

Export tab

Controls the export of images and data files.

Export tab.

Output Folder button: prompts the user to select the folder where exported data will be saved. The selected folder is displayed below the button.

Export LR button: exports data using the low-resolution, downsampled images to reduce computation time.

Export HR button: exports data using the original-resolution images.

Exp.Im.Win button: exports the current contents of the Image window as an image.

Exp.Ph.Win button: exports the current phasor plot as an image.

Im.Win.Clip button: copies the current contents of the Image window to the clipboard as an image.

Exp.Win.Clip button: copies the current phasor plot to the clipboard as an image.

Data export options:

Average decay checkbox: generates a file for each checked input file containing the average intensity in each spectral or lifetime channel.

Decay format dropdown: selects the output file format.

Pixel GS & data checkbox: generates a file for each checked input file containing the phasor coordinates and all measured phasor quantities.

Pixel GS & data format dropdown: selects the output file format.

Masked object data checkbox: if a mask is loaded, identifies objects using 8-connectivity and calculates the mean values for each object.

Masked object data format dropdown: selects the output file format.

Print colorbar checkbox: adds a colorbar showing the measured-quantity color gradient.

Save background image checkbox: exports the color gradient corresponding to the measured quantity on the phasor plot as a background image.

Phasor with axes checkbox: includes axis numbers and tick marks in the exported phasor plot.

Phasor plot alpha checkbox: exports phasor plots as PNG files with a transparent background. This option applies only when phasor plots are exported separately.

Phasor plot as checkbox: exports the phasor plot for each checked file.

Phasor plot format dropdown: Select the file format for phasor plots.

Cluster images: exports one binary mask for each cluster.

Intensity image checkbox: exports a grayscale intensity image for each checked file.

Intensity image format dropdown: selects the file format for exported images.

Quantity-colored image checkbox: exports a quantity-colored image for each checked file, using hard-mask display.

Quantity-colored x intensity image checkbox: exports a quantity-colored image multiplied by the intensity image for each checked file, using soft-mask display.

Cursor-colored image checkbox: exports a cursor-colored image for each checked file, using hard-mask display.

Cursor colored x intensity image checkbox: exports a cursor-colored image multiplied by the intensity image for each checked file, using soft-mask display.

Combine into single image checkbox: combines all selected exports for each checked file into a single file. When this option is selected, it overrides the phasor-plot file format.

Group all combined images checkbox: combines exports from all files into a single image, using the tile arrangement specified for the Image window.

Preferences (⚙) tab

Contains general settings for GSLab.

Preferences tab.

Add folder to filename checkbox: includes each file's folder path in its entry in the File tab.

Auto select tabs checkbox: selects tabs when you hover over them rather than when you click them.

Image window: show counts: displays the pixel count in a tooltip when you hover over an image in the Image window.

Keep GSLab window on top: keeps the GSLab window above other windows.

Load FLAME 31nB with B checkbox: loads the blue channel as a separate file.

FLIM LABS load option checkbox: prompts the user to choose whether to load raw or precalibrated data when loading a FLIM LABS JSON file.

Load FLIM LABS raw checkbox: loads FLIM LABS JSON data as raw data, ignoring any precalculated phasor coordinates.

Force ptufile: overrides GSLab's built-in ptu file reader and uses C. Gohlke's Python ptufile library instead.

Downsampling box: sets the downsampling factor used to create low-resolution images. Set this value to 0 to disable downsampling.

Max harmonics box: sets the maximum number of harmonics to calculate when loading data.

Marker sizes box: sets the marker size used to display points, such as components and scatter-plot points.

Density colormap dropdown: provides different color schemes for the phasor-density heatmap. If you select the last option, single color is selected the button to select color is enabled).

Quantity colormap: provides different color schemes for the phasor-based measurement. If you select the last option, single color is selected the button to select color is enabled).

Cursor colors panel: each colored button corresponds to a cursor. Click a button to open the color palette and change that cursor's color.

Auto intensity percentile: sets the data percentile used by the Auto range button in the Image tab.

Intensity histogram top pctl: sets the percentile cutoff used for normalization (Image tab, Relative checkbox) and for displaying the intensity histogram.

Auto coordinate percentile: sets the data percentile used by the Auto G and Auto S buttons in the Phasor tab.

Auto intensity percentile: sets the data percentile used by the Auto color button in the Phasor tab.

UI color button: sets the overall color theme of the user interface.

Dark mode checkbox: enables dark mode for the interface.

Reset: resets user preferences to their default values.

Update: downloads the latest version. This option is not available in the deployed Windows version.

Image Window

The Image window displays the rendered images. Hovering over an image selects the corresponding filename in the File tab and displays a black cursor on the phasor plot at the phasor coordinates of the pixel beneath the pointer. Use the mouse scroll wheel to zoom in or out of the images in each panel.

Image context menu options (right-click on image):

Freehand: allows you to draw a region of interest (ROI) freehand on the image. Click and hold while drawing, then release to close the ROI. You can drag individual ROI points or move the entire ROI.

Polygon: allows you to create a polygon ROI point by point. Click to add vertices and double-click to close the polygon. You can then edit the ROI on the image.

Rectangle: allows you to place and edit a rectangular ROI on the image.

Circle: allows you to place and edit a circular ROI on the image.

Ellipse: allows you to place and edit an elliptical ROI on the image.

Only one ROI can be active at a time. Once an ROI has been placed, you must either add it to the mask or delete it:

ROI context menu options (right-click on ROI):

Add to mask: adds the current ROI to the mask for the image. Each new ROI is assigned an incrementing label. These labels can be used for region analysis (Image tab, Integrate checkbox) and to export parameters for individual regions (Export tab, Masked obj data).

Delete ROI: removes the current ROI from the image.
