Tutorial 1 – Basic phasor analysis using lifetime measurement of a human skin biopsy

    All tutorials use one of the sample files in the FigShare package, it only needs to be downloaded once.
  1. Download the tutorial files from FigShare. [link to repo]

    2. File tab – Load files into the software

  2. Start GSLab.
  3. Click on the quick load button bottom-left (+).
  4. Select the single ref file from the SkinSlice folder.
    This is a XZ cross section of an unstained human skin biopsy taken at the NLOM lab at UCI.
  5. The phasor plot and the image will appear.
  6. Check/uncheck the file in the main panel to include/exclude it from the phasor plot.
  7. Hover over the phasor to see highlighted image regions.
  8. Use the scroll wheel to adjust the cursor size.
  9. Hover over the image to see the black cursor move on the phasor plot.

    10. Image tab – Control the rendering of the intensity image

  10. This image has a very high dynamic range, we can tune a better rendering: In the image tab, observe the intensity histogram how all the values are in the far left.
  11. Move the Right Intensity Slider halfway to reveal collagen structures.
  12. Move it further (to about 1/8th) to see the epidermis, though some bright pixels may saturate.
  13. Check/uncheck Excess to zero to exclude bright saturated pixels from the phasor plot.
  14. The image contains many low-photon pixels corresponding to outside the biopsy. We can threshold these pixels out:
  15. Uncheck Relative to show the histogram in real counts.
  16. Set the lower intensity threshold to 30 and press Enter.
  17. The phasor now excludes the pixels with low photon counts: the noisy distribution on the left part of the phasor plot has disappeared.

    18. Phasor tab – Select the phasor quantity to measure

  18. In the bottom section try the different quantities and see how the color projection changes. Use TauPhase for this dataset. Each pixel in the image is colored according to the underlying colormap in the phasor.

    19. Cursors – Place cursors on the phasor plot

  19. Depending on the settings in the previous sections, the phasor distribution may appear very differently. We may see 1, 2 3 4 or more distinct populations.
  20. Click on the phasor plot to place cursors and color the image accordingly.
  21. Use the red X button (top-right) to remove cursors (the button only appears if one or more cursors are on the phasor plot).

    22. Export tab – Save images and phasor plots

  22. Click Output Folder to choose/create a saving folder.
  23. Uncheck all checkboxhtes except for Phasor Plot as, Intensity image, Quantity-colored x intensity, and Combine into single image.
  24. Click Export LR to save the selected items.
  25. Check the output folder location: a single file should be there with grayscale intensity, phasor color projection, and the phasor plot.
  26. Uncheck Quantity-colored x intensity and check the Cursor-Colored image (place some cursors on the phasor plot if you have none there).
  27. Press the Export LR button to export like before but now the image is colored according to any cursors on the phasor plot.

Tutorial 2 – Phasor calibration and phasor filtering

  1. Download the tutorial files from FigShare. [link to repo]

    2. File tab – Load files into the software

  2. Start GSLab (or clear loaded data by Right clicking > Clear > All).
  3. Click on the quick load button bottom-left (+).
  4. Select the Lilly.re1 file from the Lilly folder.
    This is a phasor coordinate export file of a FLIM image of the root of a Lilly of the Valley Convallaria Majalis, imaged on a Lecia STELLARIS 8 FALCON.
    Courtesy of Lin Yangchen, Centre for Bioimaging Sciences, National University of Singapore.
  5. Click on the quick load button bottom-left (+).
  6. Select the Atto488.re1 file from the Convallaria2 folder.
    This is a measurement of a Atto488 solution taken right before the Convallaria image.
  7. This is a very small file (8x8=64px), which appears as a tiny point on the phasor plot close to the S axis at about s=.42, g=.02.
  8. Check/uncheck each file in the list to see their contributions in the phasor plot.
  9. Hover over the phasor plot or image window to locate the Atto488 on the phasor plot.
    Notice that it is outside of the Universal Circle.
  10. Atto488 has a known lifetime of about 4.1ns, its phasor position should be on the Universal Circle at the corresponding lifetime. We use this fact to calibrate the phasor coordinates of the biopsy values.
  11. Right-click on the Atto488 and select Calibration file.
  12. The Calibration panel unfolds showing the selected file name in the list.
  13. Use the arrow button to expand/collapse the panel.
  14. Enter 4.1 in the Calibration Lifetime (ns) field. Press Enter.
  15. Check the Apply checkbox to shift the phasor plot accordingly.
    By checking and unchecking the Apply checkbox you can see the phasor position of the calibrated and uncalibrated data
  16. Once set to 4.1ns, we can remove the calibration file:
  17. Uncheck the Atto488 filename from the list.
  18. Right-click in the empty space and select Clear > Unchecked.

    19. Image tab – Control the rendering of the intensity image

  19. Slide the right slider down to about 1/3rd of the range to saturate the brighter pixels and bring up the image brightness.
  20. Slide the left slider up to about 1/10th of the range to remove the darker pixels (notice on the phasor plot the cloud on the left dissapears).

    21. Phasor tab – Filter the phasor data

  21. Set Phasor filter to Median 3x3, 0 times and press Enter (phasor plot will look noisy).
  22. Set it to 3x3, 1 time and press Enter (reduces noise).
    The software is assigning to each pixel the median of the phasor coordinates in a window determined by the MxM value. The median is computed N times. Higher filtering smooths out lifetime values in the image.
  23. Set it to 5x5, 1 time and press Enter (reduces noise even more).
  24. Set Times to 2 and press Enter (further sharpens the phasor).
  25. In Measured quantity, click TauNorm to display the color projection to the Universal Circle.
  26. Adjust Color range to 0 and 0.5 to cover the full semicircle.
  27. Click Auto to let the software adjust the color range automatically.

    28. Display tab – Customize the phasor plot

  28. Toggle Lines, Axes, Ticks and Grid on/off.
  29. Adjust Font sizes.
  30. Toggle log density/Contours to observe the less dense regions of the phasor plot.
  31. Toggle Soft Masks to see intensity-based or color-only images.

    32. Export tab – Save images and phasor plots

  32. Click Output Folder to select a saving location.
  33. Uncheck all checkboxes except for Print colorbar, and Quantity-colored x intensity.
  34. Click Export LR to save the selected items.
  35. Two image files will be exported: the image with phasor lifetime projection, and colorbar with the lifetime values.

Tutorial 3 – Phasor calibration in multichannel data

    Attention: Ensure that the Promt FLIMlabs load option is checked to allow selecting raw data
    (Settings tab - Prompt FLIMlabs load option checkbox).
  1. Download the tutorial files from FigShare. [link to repo]

    2. File tab – Load files into the software

  2. Start GSLab (or clear loaded data by Right clicking > Clear > All).
  3. Click on the quick load button bottom-left (+).
  4. Select all 6 json files from the Convallaria folder.
    These are 2-channel measurements of Convallaria Majalis root samples and two solid calibrator measurements, one for each channel, of a known lifetime of 2.5ns.
    Courtesy of Alvaro Crevenna, EMBL Roma.
  5. The prompt should appear, select the RAW button.
  6. We have loaded the uncalibrated data which has a high phase shift and is being depicted in the second and third quadrant.

    7. Phasor tab – Select the appropriate range for phasor computing

  7. Set the G range lower and upper values to -1 and +1 respectively.
  8. Set the S range using the auto button.

    9. Image tab – Control the rendering of the intensity image

  9. Some images are much brighter; set the intensity range units to relative with the Relative checkbox.
  10. Set the intensity range using the Auto button.
  11. Inspect the distributions on the phasor plot to observe where the calibrator and convallaria samples are at.

    12. File tab – Calibrate each channel separately

  12. Select the Solid_calibrator_data_1_1756994363_phasor_ch1.json as a calibration file (Right click on it - Calibration File).
  13. The calibration panel opens, ener 2.5 in the Calibration Lifetime box.
  14. Check the Apply checkbox to shift all data accordingly. Now the file we selected for calibration should be on the universal circle at the position for 2.5ns.
  15. The selected file is in the calibration panel, with its name on the right, the assigned lifetime in the middle and a text identifier, currently 'all'.
  16. Change the identifier to apply the calibration only to specific files: double click 'All' and type 'ch1'.
  17. Check/uncheck the Apply checkbox to observe how only the channel 1 data is being shifted accordingly. The software is applying the calibration only to the files that contain the tag 'ch1' in their name.
  18. Fold the Calibration panel (using the arrow button in the bottom-right corner).
  19. Declare the Solid_calibrator_data_1_1756994363_phasor_ch2.json file as a calibration file (Right click - Calibration File).
  20. In the calibration panel change the identifier to apply the calibration only to specific files: Change 'All' for 'ch2'.
  21. The data is now calibrated, each channel with its own calibration. This can be done for any number of channels.

Tutorial 4 – Masking

  1. Download the tutorial files from FigShare. [link to repo]

    2. File tab – Load files into the software

  2. Start GSLab (or clear loaded data by Right clicking > Clear > All).
  3. Right-click in the empty space and select Load > Leica Falcon SnG.
  4. Navigate into the Organoid folder and select the phasor_data folder.
    This is a two-channel image of an intestinal organoid labeled with a membrane dye and a mitocondrial marker.
    Courtesy of Hang Zhou, University of Ghent.

    5. Image tab – Load the mask

  5. Set the intensity range units to relative with the Relative checkbox.
  6. Set the intensity range using the Auto button.
  7. Set the lower value of the intensity range to 0.1 to exlude the unmodulated light component in the background.
  8. Click on the Load mask button to and select the CellposeMask.png file in the Organoid folder. This is a 16bit integer value image from the automatical segmentation pipeline Cellpose. Each pixel is marked with an integer id that determines which cell it belongs to. GSlab assigns random colors to each object.
  9. Check the Apply mk checkbox to apply the mask image to the data. Only the pixels inside the mask are being depicted
  10. Check/uncheck the invert checkbox to see how now only the pixels outside the mask are being depicted
  11. Check the integrate checkbox. All pixels in each labeled region in the mask now take the average value of the region. The phasor plot is now a scatter plot with as many points as cells in the mask. Hover the cursor over the phasor plot to identify each cell in the image window.

    12. Export tab – Obtain object averaged parameters

  12. Uncheck all checkboxes except 'Pixel GS & data'
  13. Press Export LR button. A spreadsheet is generated for each file:
    The pixel-wise intensity, phasor and image coordinates and lifetime measurements, these are one row for each pixel inside the mask.
  14. Uncheck all checkboxes except 'Masked obj data'
  15. Press Export LR button. A spreadsheet is generated for each file together with a label reference png:
    The object-wise intensity, phasor and image coordinates and lifetime measurements, these are one row for each distinct object in the mask. The first column is the id assigned to the object which can be used to inspect the object location in the label reference png.

Tutorial 5 – Automated phasor clustering

  1. Download the tutorial files from FigShare. [link to repo]

    2. File tab – Load files into the software

  2. Start GSLab (or clear loaded data by Right clicking > Clear > All).
  3. Click on the quick load button bottom-left (+).
  4. Navigate to the folder location for the downloaded SkinSlice and select the single ref file in the folder.
    This is a XZ cross section of an unstained human skin biopsy taken at the NLOM lab at UCI.

    5. Image tab – Set the image dynamic range

  5. Uncheck the Relative checkbox to display the histogram in real counts instead of normalized intensity
  6. In the Intensity threshold values, type 30 for the lower value field (press enter).
  7. Slide the right slider down to about 1/8th of the range to reveal the structure in the epidermis at the cost of saturating the brighter pixels.

    8. Cluster tab – Perform automated clustering on the phasor plot

  8. GMM (Gaussian Mixture Model) attempts to find the linear combination of K Gaussian distributions that best fits the data.
  9. Click on the plot to leave some cursors as starting points for the algorithm. The positions and sizes are not as important, the algorithm will tune them, but the total number of clusters will be set by the number of clusters.
  10. Click on Train GMM button to generate the model.
  11. The image will be colored according to the model results.
  12. Contour lines will appear on the phasor plot, representing the Gaussian mixture model.
  13. Click on Contour separate clusters to observe the individual Gaussian of the mixture on the phasor plot.
  14. Click on Ellipse with % of data to display ellipses instead
  15. Change the percentage to display bigger or smaller ellipses.
  16. Click Apply GMM to reapply the model after changes to the image or phasor settings.
  17. The Clear GMM button will clear the current model.
  18. With Probability assign to color each pixel based on its mix of components.
  19. Click Hard assign to color each pixel based on the highest component coefficient.
  20. Check Blending to smooth color transitions.
  21. Check Override quantity for export to save GMM-clustered images instead of cursor-colored ones.

    22. Export tab – Save the results

  22. Click Output Folder to choose where to save the data.
  23. Two checkboxes now include the Cluster-colored option.
  24. Uncheck all checkboxes except for Phasor Plot as, Intensity image, Cluster-colored image, and Combine into single image.
  25. Click Export HR to save.
  26. One file will be exported, containing the grayscale intensity image, GMM-colored image, and phasor plot.
  27. Uncheck Combine into single image.
  28. Click Export HR again.
  29. Now, three separate images should appear in the output folder: phasor plot, grayscale intensity, and GMM-colored image.

Tutorial 6 – Phasor unmixing with nuclear dyes

    Attention: Ensure that the max harmonics is set to 2 in order to compute harmonics when loading
    (Settings tab - max harmonics).
  1. Download the tutorial files from FigShare. [link to repo]

    2. File tab – Load files into the software

  2. Start GSLab (or clear loaded data by Right clicking > Clear > All).
  3. Click on the quick load button bottom-left (+).
  4. Select the 5 ref files from the NuclearDyes folder.
    These are images of cell nuclei, 4 files have a single dye, the 5th contains all dyes, taken at the LFD, UCI:
    • AcO: single dye used Acridin Orange.
    • EtBr: single dye used Ethidium Bromide.
    • Nuc: single dye used NucBlue.
    • RoseB: single dye used Rose Bengal.
    • AllTogether: this dish was stained with all four dyes.
  5. Check/uncheck files in the list to see their contributions in the phasor plot.
  6. Hover the mouse on the phasor plot and scroll to change the cursor size to see the image contributions to the phasor plot.
  7. The files can be rearranged for clarity: click on the file named ‘AllTogether’ to select it.
  8. Right-click and select Move > Bot.
  9. Click on the file named ‘EtBr’ to select it.
  10. Right-click and select Move > Top.
  11. We should currently have the files sorted in descending lifetime order with the mixture file in the bottom.
  12. Check/uncheck files in the list to see their contributions in the phasor plot.

    13. Image tab – Control the rendering of the intensity image

  13. Check the Relative box so that all images are displayed in a similar dynamic range.
  14. Slide the left slider down to zero to include all dim pixels outside of the nuclei.
  15. Slide the right slider down to about 1/2 of the range to adjust the image display.

    16. Phasor tab – Filter the phasor data

  16. Change the Phasor filter Median kernel size to 7. Press Enter.
  17. Change the Times value to 2. Press Enter.
  18. In the Measured quantity section click on TauNorm.

    19. Display tab – Customize the phasor plot

  19. Check the Soft Masks checkbox.
  20. Check/uncheck Normalize by file to observe the contribution of the narrower distributions
  21. In the Source frequency edit field, enter the value of 80MHz which is the excitation frequency that was used for this dataset. This changes the lifetime values on the Universal Plot.

    22. Unmix tab – Perform unmixing of 4 components

  22. Click the + button 4 times to add 4 pure components on the universal circle.
  23. Enter the values 0.5ns, 2ns, 5ns and 20ns respectively. These are aproximately the known values for the individual dyes used in this experiment.
  24. The quadrilateral delimits the pure component locations.
  25. Check the options Export fraction im, Color components, Single image, Merge comps and Export fraction x int.
  26. Click Compute LR to launch the unmixing and save the files (in the output folder set in the Export tab).
  27. The output is an image for each component with the color-coded unmixed photon fraction in each pixel. The CompMerge.png file is the sum of the other four.
  28. Check Group by File.
  29. Click Compute LR to launch the unmixing.
  30. The output is an image for each file with the color-coded unmixed photon fraction in each pixel.
  31. Check Export fraction csv.
  32. Click Compute LR to launch the unmixing and export a csv file for each image with the unmixed photon fraction at each individual pixel.

Tutorial 7 – Spectral phasor unmixing with spectrally resolved organelle dyes

  1. Download the tutorial files from FigShare. [link to repo]

    2. File tab – Load files into the software

  2. Start GSLab (or clear loaded data by Right clicking > Clear > All).
  3. Click on the quick load button bottom-left (+).
  4. Select the lsm file from the OrganelleDyes folder. This is a culture of cells loaded with 5 organelle dyes.
    Courtesy of Leonel Malacrida and Florencia Irigoin, Universidad de la República, Montevideo.
  5. Hover over the phasor plot to see highlighted image regions:
    • Top is the nuclear dye.
    • Bottom right is the membrane dye.
    • Bottom-left is the mitochondria dye.
    • Middle-left is the Golgi dye.
    • Top-left is the Lysosome dye (practically invisible, around 10:30 area).

    Image tab – Control the rendering of the intensity image

  6. Slide the right slider down to about 1/2 of the range to adjust the image display.

    7. Phasor tab – Filter the phasor data

  7. Change the Phasor filtering value to 3. Press Enter.
  8. Change the Times value to 1. Press Enter.
  9. In the Measured quantity section click on Phase.
  10. Set the Color range to 0 and 1.

    11. Display tab – Customize the phasor plot

  11. Check the Soft Masks.
  12. Set the Spectral band range to 450 and 700nm respectively (matching the acquisition spectral detector).

    13. File tab – Load theoretical spectra downloaded from Chroma

  13. Right-click in the empty space and select Load > Trace txt/csv.
  14. Select the csv file from the OrganelleDyes folder. This is a list of the 5 emission spectra of the dyes.
  15. Hover over the phasor to find the five emission spectra as small circles.

    16. Unmix tab – Perform unmixing of 5 components

  16. In the Source radio buttons select File.
  17. The box on the left lists all files loaded. Check the 5 that correspond to the theoretical spectra of the dyes.
  18. An irregular pentagon is formed delimiting the pure component locations.
  19. Check the options Export fraction im, Color components, Single image, Export fraction x int, and Merge comps.
  20. Click Compute LR to launch the unmixing and save the files (in the output folder set in the Export tab).
  21. The output is an image for each component with the color-coded unmixed photon fraction in each pixel.
  22. The component colors can be changed with the cursor colors in the Display tab.
  23. We can go to the File tab, uncheck the pure component traces to leave only the image of the organelles, go back to the Unmix tab and run Compute LR
  24. This will create the unmixing data for just the selected file.
